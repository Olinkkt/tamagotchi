# Ideas

Possible next steps, not a roadmap. Roughly in order of payoff within each group.

## Gameplay depth

- [ ] **Balance pass**: the shop prices and coin rewards are first guesses; playtest the economy.
- [ ] **Inventory and accessories**: hats, room decorations and wallpapers, so coins have a lasting use.
- [ ] **More mini-games**: tic-tac-toe, a typing game.
- [ ] **Random events and moods**: a visitor, a gift, the pet getting lonely when you stay away.
- [ ] **Seasons and holidays**: time-of-day or date-based sprites and events.
- [ ] **Genetics or breeding**: two adults produce an egg that inherits a trait.

## Terminal-native features

- [ ] **More shell hooks**: long builds finishing, test passes, `git push`; bash and fish support.
- [ ] **More system reactions**: disk full, network down, uptime streaks.
- [ ] **Idle and typing awareness**: react to keyboard activity.

## Infrastructure

- [ ] **Download-based updater**: GitHub Actions releases, or an AUR package.
- [x] **Save migration**: saves carry a `version` field (old saves read as 0). Add real migration code when a MAJOR change needs it.
- [ ] **Sound**: terminal bell or a notification sound when the pet needs you.
- [x] **Tests**: evolution rules, profile and shop code are covered.

## Polish

- [ ] **More sprites**: extra species and evolution branches.
- [ ] **Action animations**: eating, cleaning, evolving.
- [ ] **Stats screen**: age, lifetime care score and games won per pet.
